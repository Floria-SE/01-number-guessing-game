# 数当てゲーム

・数をランダムで生成して、その数字を当てるゲーム
・Pythonの基礎学習のために作った

## 学習したこと

- `print()`：文字を表示する
- `input()`：プレイヤーから入力(str型)を受け取る
- `if / elif / else`：条件で処理を分ける
- `int()`：文字列を整数に変換
- `import`：モジュールを読み込む
- `while`：処理を繰り返す
- `break`：処理を終了する
- `continue`：現在の処理を飛ばして次の処理に移る
- `try / except`：エラーが発生した時の処理を行う
- `random.randint()`：指定した範囲からランダムな整数を生成する

## 工夫したこと

1~100の整数以外が入力された場合は、プレイ回数に含めないように処理の順序を工夫した

## 実行方法

1. `main.py`をVS Cordで開く
2. 右上の三角マーク（実行ボタン）を押す
3. ターミナルに表示された案内に従って数字を入力する
